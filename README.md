# VerifiAgent

This is the official code for the EMNLP 2025 Findings paper: [VerifiAgent: a Unified Verification Agent in Language Model Reasoning](https://arxiv.org/pdf/2504.00406v2).

Our search engine API is using [Perplexica](https://github.com/ItzCrazyKns/Perplexica), you need to implement this before use.
