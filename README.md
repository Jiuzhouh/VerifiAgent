# VerifiAgent

This is the official code for the EMNLP 2025 Findings paper: [VerifiAgent: a Unified Verification Agent in Language Model Reasoning](https://aclanthology.org/2025.findings-emnlp.891.pdf).

Our search engine API is using [Perplexica](https://github.com/ItzCrazyKns/Perplexica), you need to implement this before use.
